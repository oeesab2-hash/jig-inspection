เปิด GPS เพื่อใช้งาน

แอป JIG Inspection ต้องการ GPS เพื่อบันทึกพิกัดการตรวจเช็ค

วิธีเปิด GPS:

  • Android: Settings → Location → ปิด → เปิด
  • iOS: Settings → Privacy → Location → ปิด → เปิด

จำเป็นต้องเปิด GPS ก่อนใช้งาน
